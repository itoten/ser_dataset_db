## 1. About this config

Experiment multidataset_ser_01 (conditions given by the maintainer, 2026-11-04).

- The trained model is released under an open license that allows commercial use, so datasets that
  forbid commercial use cannot be used for training.
- The datasets are not redistributed (each user downloads them through the ESPnet recipes).
- These steps only decide which datasets can be used at all. Training/evaluation roles by license are
  decided later (discussion 0003 in docs/discussions/).
- A step removes a dataset only when the DB says it fails. When the DB does not say, the dataset is kept
  as "kept_unverified". The license step is the exception: an unknown license is removed.
