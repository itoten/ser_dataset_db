# 0003 ライセンスの区分: 何のために分けるのか

状態: 議論中
関連: [discussions/0002](0002-separate-implementation-and-use.md)(7.5〜7.7 の続き。条件 C4)
最終更新: 2026-11-04

対象は `local/license/`(git 管理外)の区分と、実験 `multidataset_ser_01` で区分をどう使うか。DB の `license_spdx` は事実(資料の記述)で、この区分は研究の判断なので、区分そのものは `local/` に置く(公開 DB には書かない)。

## 1. 前提(maintainer、2026-11-04)

- **この実験では、ライセンスが明確なら、ライセンスが何であれ使ってよい。**
- **ただし、学習に使うか評価に使うかを、ライセンスで決める。** そのため、明確なライセンスの中でも、**商用利用ができるかどうか(NC かどうか)** が大事な点になる。これまで open かどうかを気にしてきたのは、このため。
- 議論 0002 の 7.5 で「SA 系は除外」とした決定は、この前提を確かめる前のもの。この議論で見直す。

## 2. 問い

1. **SA(継承)は、そのデータで学習したモデルに、どんな影響を与えるか。** それによって、SA のデータを学習側に入れてよいかが決まる。
2. **`research_only` と `restricted` は、NC にまとめてよいか。** 明確に open でないものは、学術研究の目的で使うだけなので、それ以上細かく分ける必要は無いのではないか(学術研究も禁じるものなら別)。
3. **区分は「open / NC / 不明・未確認」の 3 つで足りるか。**

## 3. 資料に書いてあること

Creative Commons(CC)の公式の解説 2 つ。どちらも 2026-11-04 に読んだ。法律の助言ではなく、CC 自身の説明である。

### 3.1 「Using CC-Licensed Works for AI Training」(creativecommons.org、日付の表示なし)

- **ライセンスが効くのは、著作権の許諾が必要なときだけ。** 例外や制限(国の法律による)に当たる使い方には、ライセンスの条件はかからない。著作権がかかるかは国によって違う。
- **学習では、作品を複製することが多い。** また、モデルが学習データの表現を記憶する(memorization)ことがあり、どの程度かを理論的に測る方法は無い、とする。
- **BY(帰属表示):** 学習データとしてなら、データセットの出典へのリンクで足りうる。
- **SA(継承):** BY-SA と BY-NC-SA は、改変物を同じライセンスで出すことを求める。**モデルや出力が SA のデータから作られ、公開されるなら、SA の条件に従うことは、開発者が元と同じ CC ライセンスを付けることを意味する**(「if ... would」の条件つきの書き方)。
- **NC(非営利):** NC のデータで学習するなら、学習中の複製から、学習したモデルの配布まで、すべての段階が商業目的であってはならない。
- **条件がかかる時点:** BY・SA・ND の条件は、作品や改変物を公開したときにだけかかる。NC は、許諾が必要なすべての使い方にかかる。

### 3.2 CC の FAQ(creativecommons.org/faq/、「Artificial intelligence and CC licenses」と「Data」の節)

- ライセンスは、著作権がかかる新しい技術にもそのまま使えるように作られている。著作権の許諾が要らない使い方(フェアユースなど)には、ライセンスは関係しない。
- SA は、作品を改変して公開したときにだけかかる。公開しなければ、SA の条件は生じない。
- テキスト・データマイニングについて: NC のデータは商業目的でマイニングしない。SA のデータの改変物には、同じライセンスを付ける。

### 3.3 読んでいないもの

GPL(ソフトウェアのライセンス)と ODbL(データベースのライセンス)が、学習したモデルにどう効くかは、まだ一次資料を読んでいない。どちらも継承(コピーレフト)の条件を持つ。

## 4. 整理(Claude の考え)

### 4.1 SA

- 学習に SA のデータを使い、**モデルを公開しないなら**、SA の条件は生じない(3.1、3.2)。
- **モデルを公開するなら**、CC は「同じライセンス(CC BY-SA)を付けることになる」と書いている。モデルが改変物に当たるかどうかは、法的にはっきりしていない(3.1 は条件つきの書き方で、断定していない)。
- したがって、SA のデータを学習側に入れると、**公開するモデルに CC BY-SA を付けるか、その危険を受け入れるか** になる。学習用を「商用でも使える」データにする目的が、「作ったモデルを自由に公開・利用できるようにする」ことなら、SA はその目的に合わない。
- 選択肢:
  - A: SA を学習側(open と同じ)に入れる。モデルを公開するときは CC BY-SA を付ける覚悟をする。
  - B: SA を評価側(NC と同じ)に入れる。学習したモデルに継承の条件が及ばない。評価にだけ使うなら、改変物を公開しないので SA は生じない。
  - C: SA を独立の区分にして、実験ごとに決める。
- **私の考え: B。** 学習側を「モデルに条件が及ばないもの」だけにすれば、モデルの扱いが一番単純になる。評価には SA でも問題なく使える。

### 4.2 `research_only` と `restricted` を NC にまとめる

- 評価に使うだけなら、学習したモデルにデータの条件は及ばない。学術研究で評価に使うことを禁じていない限り、`research_only` と `restricted` を NC と分ける理由は無い。
- まとめる前に確かめること:
  - 学術研究での利用を認めているか(`research_only` は定義上認めている)。
  - `restricted` は、有料や個別の契約。実装済みでは CASIA の 1 件だけで、これは除外リストに入れた(非公式ミラー)。今の実装済みには残らない。
  - 結果(評価の数値)を論文で公開することを禁じる独自の条件が無いか。今の DB の `license_note` を見る限り、そういう記述は見つけていない(すべてを確かめたわけではない)。

### 4.3 区分の案

| 区分 | 意味 | 学習 / 評価 | 含めるもの |
|---|---|---|---|
| `open` | 商用利用ができ、継承の条件が無い | 学習(評価にも使える) | CC0、CC BY、MIT、Apache、ODC-By |
| `noncommercial` | 商用利用ができない、または継承の条件がある(B 案の場合) | 評価だけ | CC BY-NC、CC BY-NC-ND、CC BY-NC-SA、独自の研究用、有料・独自の条件、(B 案なら)CC BY-SA・GPL・ODbL |
| `unclear` | ライセンスが明確でない | 使わない | `none_stated`、`unknown`、引用だけを求めるもの、`conflicting` で決められないもの |
| (未確認) | DB で未確認 | 判定できない | `license_spdx` が空欄 |

- `conflicting` は、0002 の決定どおり、食い違う記述のうち厳しい方の区分をとる。
- `other`(独自の文言で、上に当てはまらないもの)は、1 件ずつ文言を読んで、3 つのどれかに入れる。区分としては残さない。

### 4.4 今の実装済みでの数(2026-11-04、除外リストの 2 件を含む 102 件)

| 今の区分 | 件数 | 4.3 の案での行き先 |
|---|---|---|
| `open` | 57 | `open` |
| `share_alike` | 9 | A 案なら `open`、B 案なら `noncommercial` |
| `noncommercial` | 5 | `noncommercial` |
| `noncommercial_share_alike` | 8 | `noncommercial` |
| `research_only` | 12 | `noncommercial` |
| `restricted` | 1 | `noncommercial`(CASIA。除外リストで外れる) |
| `other` | 1 | 文言を読んで決める |
| `unclear` | 9 | `unclear` |

## 5. 決めてほしいこと

1. **SA をどう扱うか**(4.1 の A / B / C)。
2. **`research_only` と `restricted` を NC にまとめてよいか**(4.2)。
3. **区分を `open` / `noncommercial` / `unclear`(+ 未確認)の 3 つにしてよいか**(4.3)。
4. **C4 の条件を「区分が `unclear` でない」に変えてよいか。** 区分は C4 では使う・使わないを決めるだけにして、学習・評価の役割は別の列(後で決める)で、区分から決める。
5. **GPL と ODbL** は、一次資料を読んでから決めるか、SA と同じ扱いにするか。
